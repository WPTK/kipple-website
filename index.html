Self-hosted RSS reader.

Kipple syncs with Reeder Classic and NetNewsWire, keeps everything in SQLite, and runs as one container on one port. It's built to look good while you read.

Why another RSS reader

I wanted one reader with the best parts of all the others, and I didn't want to give up a good-looking app to get it. So I started building one with Claude Code and kept going.

Feedly's magazine layout is the look. FreshRSS and Miniflux set the flavor of the sync API. It replaced yarr on my own server, and it's what I read my feeds in now.

How it works

refresh
Every 30 minutes, or on a schedule of its own for any feed that needs one. A feed that keeps failing gets checked less and less often instead of hammered.
retention
Each feed keeps its newest 50, 100, 250, 500 or 1000 items, or everything. Set it once for all feeds, then override the noisy ones.
sync
The Google Reader API, the one FreshRSS and Miniflux speak, at /api/greader.php. No Fever.
themes
20 color schemes, with separate picks for day and night. The buttons at the top of this page are the real ones.
fonts
Eleven fonts ship inside the container, so opening Kipple never calls out to a font CDN.
stats
Reading time only counts while the tab is in front and focused. Leaving it open overnight doesn't make you a fast reader.
runs as
uid 65532 on a read-only filesystem, every Linux capability dropped, capped at 256 MB of memory.

Anti-features

  • No AI
  • No notifications
  • No social
  • No monitoring or telemetry*

*Unless you turn on reading stats. Those are stored locally, in your own database, and they never leave it.

Reeder and NetNewsWire

Reeder Classic is the primary client and NetNewsWire is the second. Both get tested. Anything else that speaks the Google Reader API might work, but I haven't tried it.

Build it

There's no published image yet, so you build it from source. Docker is all you need.

# get the source and build the image
git clone https://github.com/WPTK/Kipple.git
cd Kipple
cp .env.example .env
docker build -t kipple:latest .

# start it
docker compose -f docker-compose.example.yml up -d kipple

Open 127.0.0.1:7080. To bring your feeds over, pipe an OPML file into kipple import -. Backups, recovery and reverse-proxy notes are in docs/deploy.md.

Where it stands

v0.3.0-alpha.1 is the first public build. Fetching, sync and the reading UI run daily. Installable-app and offline support are next.
