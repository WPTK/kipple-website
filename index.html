Self-hosted RSS reader.

Kipple keeps everything in SQLite, runs as one container on one port, and syncs with any app that speaks the Google Reader API.

What it looks like

The web app in Paper and Midnight, on desktop and phone. The sample feeds are public, including the Wikimedia Commons picture of the day; credits are on Commons.

Why another RSS reader

I wanted one reader with the best parts of the others. Kipple is built with Claude Code.

The layout is magazine-style, with images up front. It has one user.

How it works

refresh
Every 30 minutes, with an optional interval per feed. A failing feed backs off. You can refresh everything by hand.
folders
Folders nest up to eight levels deep. OPML import and export keep the tree.
retention
Each feed keeps its newest 50, 100, 250, 500 or 1000 items, or all of them. Set it globally, then per feed.
sync
A Google Reader compatible API at /api/greader.php.
themes
Color schemes, with separate picks for day and night.
fonts
Reading fonts, including Atkinson Hyperlegible.
stats
Reading time counts only while the tab is visible and focused.

Anti-features

  • No AI
  • No notifications
  • No social
  • No monitoring or telemetry*

*Kipple keeps reading statistics in your own database. Nothing is sent anywhere.

Bring your own client

Any app that supports a Google Reader compatible account can sync. Setup steps are in the README.

Install it

Kipple is a signed Docker image for linux/amd64 and linux/arm64.

docker run -d --name kipple --restart unless-stopped -p 127.0.0.1:1919:1919 -v kipple_data:/data --read-only --tmpfs /tmp:size=64m,mode=1777 --cap-drop ALL --security-opt no-new-privileges ghcr.io/wptk/kipple:1.5.1

Or as a compose file. Save it as docker-compose.yml and run docker compose up -d.

services:
  kipple:
    image: ghcr.io/wptk/kipple:1.5.1
    container_name: kipple
    restart: unless-stopped
    ports: ["127.0.0.1:1919:1919"]
    volumes: ["kipple_data:/data"]
    read_only: true
    tmpfs: ["/tmp:size=64m,mode=1777"]
    cap_drop: [ALL]
    security_opt: ["no-new-privileges:true"]
volumes:
  kipple_data:

Open http://127.0.0.1:1919 on the machine that runs Kipple. The port is published on that machine only.

If Kipple runs on another machine, open an SSH tunnel from the computer you browse on and leave it open:

ssh -L 1919:127.0.0.1:1919 you@your-server

Until you create your account, anyone who can reach the port can claim it. Do not expose Kipple on the open internet over plain http; put HTTPS in front of it.

A backup file holds password hashes and feed logins. Keep it private.

To build from source, see the deploy guide. You need Docker and Git. Backups, recovery and reverse-proxy notes are in docs/deploy.md.

First run

The first screen creates your account.

Every step after the account can be skipped: time zone, look, import (OPML), recommended feeds, server address, app password.

No password? The account step offers to go without one. An instance with no password must be reachable only from localhost or over Tailscale, a private VPN. Anyone who can reach it can read and change everything. Kipple refuses open sign-in through a reverse proxy or tunnel.
